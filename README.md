# Python File Organizer

A simple Python project that automatically organizes files into different folders based on their file extensions.

## Features

- Organizes image files into an Images folder
- Organizes document files into a Documents folder
- Places all other files into an Others folder
- Automatically creates folders if they do not exist
- Beginner-friendly Python project

## Technologies Used

- Python
- os module
- shutil module
